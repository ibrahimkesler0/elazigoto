# Gold Oto Kiralama — Elazığ Web Sitesi

Elazığ Merkez'de 7/24 araç kiralama hizmeti sunan **Gold Oto Kiralama** için site boyunca kesintisiz devam eden, kaydırmaya bağlı 3D araç koreografili ve interaktif 3D Showroom'lu kurumsal web sitesi.

- **Canlı Adres:** https://elazigoto.vercel.app
- **Teknoloji:** Vite + Vanilla JS, Three.js (GLTF + Draco + WebP + özel stüdyo PMREM ortamı), Swiper
- **3D Model:** Sketchfab kaynaklı CC-BY-4.0 lisanslı `BMW M4 Competition M Package` (SRT Perfomance™), Draco & WebP ile `1.99 MB` boyutuna optimize edildi (`public/models/bmw-m4.glb`)
- **İşletme Verileri:** Google Haritalar kaydından doğrulanmış adres, telefon, 7/24 çalışma saatleri ve 5,0 yıldızlı gerçek müşteri yorumları (`src/data.js`)

## Geliştirme

```bash
npm install
npm run dev
npm run build
```
